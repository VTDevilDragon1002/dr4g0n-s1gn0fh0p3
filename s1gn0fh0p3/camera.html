Working AI Hand Sign

Hand Sign Recognition

Real camera detection using MediaPipe Hands. It detects finger count and common signs like open palm, fist, thumbs up, thumbs down, OK, call me, and I love you.

For best camera working, open the project using start-server.bat and visit http://localhost:5500.

How to make camera work perfectly

1

Do not open only by double click

Browser may block camera in file mode.

2

Run server file

Double-click start-server.bat on Windows or run python -m http.server 5500.

3

Use Chrome / Edge

Allow camera permission and keep your hand fully visible.
